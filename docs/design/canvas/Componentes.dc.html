Componentes: shadcn/ui dentro del diseño atómico

shadcn/ui copia el código de cada componente al proyecto (Radix para el comportamiento accesible y Tailwind CSS v4 para el estilo), así que lo podemos adaptar sin pelearnos con una librería cerrada. Encima de esa base van nuestros niveles atómicos. Los componentes hablan de "elementos" y no de "canciones" para que sirvan a cualquier dominio.

components/ui/ Lo que genera npx shadcn add. Se toca lo mínimo y no se importa desde las páginas.
atoms/ · molecules/ Envuelven ui/ con nuestras variantes (cva) y la API del dominio.
organisms/ · templates/ Bloques con datos y marcos de pantalla. Sin llamadas a la API.
pages/ Conectan rutas, datos (TanStack Query) y estado. Una por pantalla.
shadcn: Button= se basa en ese componente de shadcn/ui o Radix propio= sin equivalente, se construye con Tailwind
